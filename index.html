The discovery

The reported test involves a demo account and Amethyst's local account data. A change to local metadata may affect how a launcher behaves, but that alone does not prove that a paid license has been unlocked.

1

Log in to your demo account

Open Amethyst and sign in to the demo account you want to test.

2

Find the account file in Files

Open the Files app on your iPad, navigate to Amethyst's folder, and locate the account JSON file.

3

Review the JSON carefully

Your reported method is to ask an AI to remove the demo entry and adjust the JSON filename. Never upload a file that contains passwords, access tokens, or other private credentials to an AI service.

4

Replace the local file

Replace the demo account file with the edited file, then reopen Amethyst and check what changes. Keep a backup of the original file so you can restore it if needed.

5

Check what the result actually means

This may change local launcher behavior, but it does not grant a Minecraft license. To access the paid game legitimately, use an account that owns Minecraft Java Edition.

Tip: avoid sharing account JSON files publicly. They may contain sensitive session or account information.

⚠️ Disclaimer

This method only changes local account data in Amethyst. It may trick the launcher into treating a demo account as a paid account, but it does NOT unlock or grant a legitimate Minecraft Java Edition license. Your actual Minecraft ownership and account permissions remain unchanged.

Results may vary depending on your Amethyst version and account configuration.
